# Documentation review

## Scope

The root overview and directory guides describe the implemented pipeline,
separate historical routes from current model contracts, and preserve the
MILPBench download presentation. Reviewed comments, docstrings and display
messages use academic English. Mathematical identifiers and CLI contracts are
unchanged. The preserved legacy Gasse source remains a historical reference;
the completed confirmation used the explicitly versioned alternating-prenorm
model.

## Experimental reconciliation

The [final confirmation evidence](results/pr50-confirmation/README.md) supports
39 admitted original parents, 100 epochs, and held-out evaluation on eight
parents. The initial 42-parent target remained incomplete. Medium instances
3, 5 and 6 were excluded for gaps above 10% after four-hour solves; source
receipts and the outcome-conditioned selection are retained.

Documentation reports aggregate and parent-macro classification, ranking and
calibration diagnostics without converting them to solver-performance claims.
Graph statistics and PCA/k-means are descriptive. Full four-arm comparison,
native guidance benchmarking, multi-seed replication, dependency qualification
and the full 90-parent campaign remain future work.

## Reproducibility boundaries

Comments and docstrings participate in source fingerprints. Editorially
equivalent code can therefore have a new byte hash; historical receipts must
not be rewritten. The public evidence audit verifies the transferred files,
not omitted tensors, labels, checkpoint or predictions. The initial and revised
cohort contracts remain separately identifiable.

MIT covers original project code, documentation and generated research material
within the authors' rights. MILPBench, solver and third-party template terms
are unchanged. See [LICENSE_POLICY.md](../LICENSE_POLICY.md).

## Verification

Documentation tests check the preserved download links, current/historical
distinction, result statements, internal navigation and LF-only launchers.
The combined source snapshot includes the merged confirmation implementation;
licensed tests remain explicitly skipped when no local license is available.
No HPC result was regenerated or changed for this editorial reconciliation.
