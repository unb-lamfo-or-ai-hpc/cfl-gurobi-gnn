# Architecture decision records

ADRs preserve the rationale and constraints accepted at a particular stage.
Do not rewrite historical decisions to imply that subsequent experiments had
already succeeded. Read status, supersession, and the associated runtime gate.

[ADR 0013](0013-gurobi-first-legacy-recovery.md) governs the recovered
Gurobi-first graph pipeline; [ADR 0014](0014-neural-guidance-policy.md) governs
native guidance semantics. Earlier ADRs explain parent-level splitting,
synthetic descendants, solver probes, and historical engineering paths.

Implementation sequences in older ADRs are dated plans. For present navigation,
use the [documentation index](../README.md), not an old PR-number sequence.
