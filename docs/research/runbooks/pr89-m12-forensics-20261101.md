# Closed-file collection for the M12 numerical audit

1 November2026. Author CLI intervention only; the agent does not access HPC.
This collection supports the [specific gap/search audit](../pr89-m12-gap-audit-20261101.md).
It does not launch a numerical experiment or change PR89.

The [stdlib-only exporter](pr89_m12_forensic_export.py) reads only the original
M12 input, closed artifacts of jobs3725–3728, existing binding metadata and
the frozen campaign controls. The only subprocesses are read-only Git
identity queries and `sacct` for those four jobs. It imports no solver,
training library or campaign operator. It does not decompress vectors or
perform optimization, inference, relaxation, preparation or scheduling.

The author can paste its contents in the existing `tfm_env` Bash session as
`python -B - <<'PY'`, followed by the complete Python source, then a final
`PY` on a line by itself. The `-B` flag avoids Python bytecode files. A
complete copy/paste wrapper and a guarded PowerShell SCP block are provided
in the local Codex temporary workspace with the delivery of this runbook.
No installation or checkout on HPC is required.

Before export, it checks host/user/environment, frozen Git commit/tree,
plan/preflight/authorization hashes, four COMPLETED accounting roots with
exit0:0, the four received child hashes, child-to-cell/submission bindings,
nested supervision/cost seals, closed-log seals and the original LP hash.
Model/vector/metadata size caps are enforced; aggregate input is limited to
768MiB, and the model to512MiB. Streaming hashes avoid loading these files
into memory as whole byte arrays. Hashing and compression still use local
CPU and file I/O on the shared host; they are not cost-free monitoring.

The sole new HPC file is a UUID-named private ZIP in the existing CPU12h
stage directory. No new directory is created; `/home` and installed source
are not written. Originals are rehashed before/after each copy; archive
members are independently rehashed. Existing ZIPs cannot be overwritten.
If collection fails, preserve its output and any incomplete ZIP; do not
manually overwrite or delete evidence or run campaign operators.

The private ZIP contains the unchanged model and four original compressed
solution files, closed solver logs, existing receipts, intent/profile
metadata, the accounting response and a manifest. Solution hashes are
**observed at collection**, not historical seals: public children did not
export their solution-file hashes. Log and child hashes are historical
seals. The archive remains private in the local Codex temporary directory;
do not commit it, its variable values, raw model or raw logs to GitHub.
Only sanitized findings belong in the PR.

Success prints five lines: `ARQUIVO_HPC`, `SHA256`, `JOBS_COLETADOS`,
`OTIMIZACOES_NOVAS=0`, `BYTES_ZIP`. The author then uses local PowerShell
SCP, enters the password only in that terminal, and compares the received
SHA256 before providing the local path. The transfer block accepts only
the expected stage/UUID filename and creates a new local UUID filename.

Validation:12 synthetic tests cover a complete round trip with unchanged
inputs, active/foreign/duplicate job rejection, tampered children/log/model,
path escape, size cap, exclusive creation, concurrent mutation detection and
absence of solver/campaign imports or mutating subprocesses. These tests do
not establish HPC availability or actual raw-vector feasibility; those
remain pending the author's collection and independent offline review.
