# Research notebooks

[pipeline_smoke.ipynb](pipeline_smoke.ipynb) is an exploratory entry point.
Notebook output, execution order, and local paths are not acceptance authorities.
Use the versioned CLI plans and audited reports for reproducible experiments.

Before sharing a notebook, inspect stored outputs and metadata for credentials,
private paths, stale metrics, and unexecuted cells. Do not silently regenerate
historical results or present a notebook illustration as a completed campaign.
