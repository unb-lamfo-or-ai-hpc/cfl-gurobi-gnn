# Validation evidence

This directory contains reviewed, bounded validation notes, including the
[initial parent-instance smoke](2026-08-30-instance-baseline-smoke.md).
A receipt applies to its recorded code, artifact hashes, population, and runtime.

Do not extrapolate a toy or one-parent smoke to the 42-parent confirmation,
a paired four-arm study, GPU/DDP parity, or the full 90-parent population.
Preserve failed and censored runs separately from successful engineering gates.
Publish sanitized summaries only; raw logs may contain private paths or license
metadata.

See [reproducibility](../reproducibility.md) for acceptance and disclosure rules.
