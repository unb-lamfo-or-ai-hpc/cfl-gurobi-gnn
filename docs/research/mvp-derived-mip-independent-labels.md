# Independent labels for MVP local-branching MIPs

## Purpose

PR #27 independently solves the local-branching MIPs generated by PR #25.
Each solver processes only the candidates generated for its own arm.  The
source incumbent defines the local-branching constraint but is never supplied
to the independent solve as a warm start.

This gate produces labels and their performance provenance.  It does not build
graphs, admit samples to training, or make solver-performance claims.

## Symmetric solve contract

Both arms use:

- a fresh process per candidate;
- the derived LP as the only model input;
- effective objective sense `MINIMIZE`;
- no warm start and no source-incumbent injection;
- the default solver profile;
- one thread, seed 42, a one-hour time limit and the same node limit;
- passive online incumbent capture with full vectors written to Parquet;
- terminal relative MIP gap and solver wall time as the primary stored tags;
- an inclusive label-admission threshold of 10% relative MIP gap.

The PySCIPOpt arm reuses the `BESTSOLFOUND` kernel validated by PR #26.  The
Gurobi arm uses a lightweight `MIPSOL` callback.  `MIPNODE` is intentionally not
collected during label generation because node relaxations are not required by
this gate and would materially increase I/O.

## Execution and interpretation

The three candidates in one arm may run concurrently in three independent
processes.  Parallelism, hardware allocation, solver versions, parameter hashes
and censoring status are recorded.  These execution times describe label
generation and are not the final comparison between Gurobi and SCIP.  The
four-arm scientific comparison will use a separately controlled evaluation
protocol.

A candidate passes when it has a feasible named solution, a complete and
consistent online incumbent trace, a committed vector stream, and terminal gap
at most 10%.  A valid solve that reaches the budget with gap above 10%, or with
no feasible solution, is inconclusive and may be resumed with a larger budget.
Instrumentation, provenance or callback failures fail closed.

Even a passing label remains `dataset_eligible=false` until PR #28 constructs
and audits its graph and emits the solver-neutral sample manifest.

## Outputs

- `derived_mip_solution_plan.json`: immutable cohort and solve contract;
- `derived_mip_solution_report.json`: aggregate gate and sensitivity counts;
- `per_candidate_derived_metrics.jsonl`: one auditable record per radius;
- `solutions/*.solution.json.gz`: named final solutions;
- `incumbents/*.incumbents.parquet`: online full incumbent vectors;
- `variable_orders/*.variable_order.json.gz`: vector mappings.
